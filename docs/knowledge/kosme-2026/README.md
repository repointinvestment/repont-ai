- 융자한도: 기업당 60억(잔액+신규 합산). 지방소재 70억, 사업별 우대·정부정책 우대 100억.

- 융자제외 업종(별표1): 주점업(5621), 부동산업, 금융·보험업, 법무·회계·세무, 보건업, 초중고·입시교육, 사행성·유흥, 협회·단체 등. **일반 음식점은 제외 업종이 아님** — 요식업이 실제로 못 받는 건 소상공인 제외(⑨)·부채비율·심사 때문.
